# BlueDragon installer

`bluedragon-1.0` is an ARM64 comma installer configured to clone
`https://github.com/Autogarsas/BlueDragon.git`, branch `bluedragon-1.0`.
Its download URL is:

https://raw.githubusercontent.com/Autogarsas/BlueDragon/bluedragon-1.0/installer/bluedragon-1.0

The upstream executable is generated by comma's `installer.comma.ai` service.
The fork-installer mechanism intentionally leaves a padded repository URL and
branch string; the documented `get_str()` function reads up to the `?` marker.
Only that existing repository URL parameter has been changed here. The file
length, branch, executable instructions, and other bytes are unchanged.

`build.json` records the source URL, source and output SHA-256 values, parameter
buffer location, and source reference. `tools/ford_bluepilot/build_installer.py`
reproduces the parameter change from a matching downloaded upstream binary.
The installer itself is derived from comma.ai/openpilot; its original license
is retained in the root LICENSE. See CREDITS.md for the project attribution.

The configured URL and branch, ELF architecture, unchanged bytes outside the
parameter, and file checksums have been checked on the host. The complete
installation has not been exercised on a device. No installer is run by the
build script; it only writes the configured executable.
